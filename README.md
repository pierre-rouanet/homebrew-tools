# homebrew-tools

A personal Homebrew tap.

## rkdeveloptool

Rockchip's USB flashing tool, for boards in maskrom or loader mode. Built from upstream source.

```bash
brew install pierre-rouanet/tools/rkdeveloptool
```

## duckctl

Talks to a Microduck robot from a laptop, over Bluetooth LE. Installs the release binary
published on PyPI, so no Rust toolchain is needed.

```bash
brew install pierre-rouanet/tools/duckctl
```
