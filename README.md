# homebrew-tools

```bash
brew install pierre-rouanet/tools/rkdeveloptool
```

```bash
brew install pierre-rouanet/tools/duckctl
```

| formula | what |
|---|---|
| `rkdeveloptool` | Rockchip's USB flashing tool (maskrom / loader mode), built from upstream source |
| `duckctl` | Talk to a Microduck robot from a laptop, the release binary from PyPI |
